# Habit Builder 

Habit Builder is a mobile productivity application designed to help users build consistent habits through daily task management, reminders, daily task completion progress, and task history.

Built with Python and Kivy, the application is designed to work completely offline using local storage, allowing users to manage their habits without an internet connection.

---

## Features

- Create daily tasks
- Edit existing tasks
- Delete tasks
- Reminder notifications
- Snooze reminders
- Mark tasks as completed
- Daily progress tracking
- Task history
- Copy yesterday's schedule
- Offline data storage
- Animated splash screen
